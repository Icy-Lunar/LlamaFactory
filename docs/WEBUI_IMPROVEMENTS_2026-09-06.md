# WebUI 改进说明：2026-09-06

本文说明相对上次训练专用版本 `07482a4f` 的更新，以及当前版本相对原版 LLaMA Factory 的主要产品差异。

## 本次更新

| 领域 | 改进 | 使用效果 |
| --- | --- | --- |
| 量化选择 | 第一步默认不量化，用户自行选择位数；自动推荐不再强制写入 4-bit | 根据模型和资源自主选择，所选量化参与实时显存估算 |
| 微调方式 | 首屏提供 Full、Freeze、LoRA 和 OFT；Full/Freeze 禁用不兼容的权重量化 | 不再局限于 LoRA，并减少错误组合 |
| 按需参数 | 增加样本上限、调度器、梯度裁剪、随机种子、日志与保存间隔、预热步数和 Packing | 常用设置可展开修改，默认界面仍保持简洁 |
| LoRA 参数 | LoRA 分支显示 Rank、Alpha、Dropout、RS-LoRA 和 DoRA | 仅向使用 LoRA 的用户展示适配器调优选项 |
| 多模态识别 | 读取本地 `config.json` 的视觉配置和模型标识 | 适用时显示多模态参数，无须模型目录名匹配预设列表 |
| 视觉训练 | 接入视觉编码器、多模态投影器及语言模型冻结开关，保留图像/视频像素范围 | 参数传入最终训练配置，视觉结构、冻结状态和最大像素值参与估算 |
| 视觉样式 | 统一蓝灰配色、深浅主题、卡片和输入框间距；紧凑页头加入工作区与语言切换 | 训练与合并页面风格统一，窄屏自动换行 |
| 操作反馈 | 增加按钮悬停、键盘焦点和禁用状态，修复警告窗口隐藏样式 | 隐藏遮罩不拦截点击，风险操作状态更明确 |
| 警告返回 | “返回调整配置”关闭风险窗口并回到参数页，重置强制确认状态 | 用户能直接调整参数后重新检查 |
| 适配器合并 | 合并按钮读取合并页实际选项，展开检查点列表保留当前选择 | 修复选择了适配器但合并动作未使用该选项的问题 |
| 量化兼容性 | 切换量化算法保留兼容位数，不兼容时重置为不量化 | 避免遗留不受支持的位数 |
| 本地化 | 新增说明统一纳入英语、简体中文、俄语、韩语和日语资源 | 切换语言不覆盖手动训练参数，输出目录标签保持正确 |

## 当前相对原版的产品差异

- WebUI 主要工作区为四步引导训练和适配器合并，保留训练所需的参数分支。
- 模型只从已有本地目录读取，不通过本框架下载模型；权重规模由本地文件汇总得到。
- 默认使用 `liger_kernel`，依赖要求为 `liger-kernel>=0.8.0`。
- 自动配置允许手动修改；参数阶段提供实时显存估算，启动前再用当前参数检查。
- 显存建议值为估算峰值的 `1.10` 倍；不足或无法确认时提供风险警告和显式确认。
- 本次同步仅更新 Cyrene 插件目录，保留其调度集成说明和插件目录外的业务代码。

## 估算边界与后续改进

> 2026-11-03 更新：现行实现已改为解析 safetensors 张量元数据，并分别计算模型权重、训练状态、训练/验证激活峰值和运行时空间；验证 batch 不再直接代入反向传播公式。以下边界说明仍然适用。

显存结果是风险筛查用的启发式估算。多模态训练仍需近似实际图片数量和视频帧数；最大像素值不能代表每条样本的完整媒体构成。10% 余量不是误差上限，不能保证不会发生 OOM。

后续可根据真实训练峰值校准不同模型与硬件的估算系数，并加入样本图像数量、视频帧数和更精确的视觉参数统计。Cyrene 的正式产品执行入口仍以其 `TrainingRuntime` 与 `TrainingExecutor` 为准，插件内 Gradio Runner 的本地兼容入口没有在本次更新中改造。

完整使用说明见 [现行 WebUI 文档](CYRENE_YIELD_WEBUI.md)。
